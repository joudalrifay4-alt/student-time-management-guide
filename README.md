# دليل إدارة الوقت والتركيز للطلاب

دليل بسيط يقدّم نصائح عملية للطلاب لتنظيم وقتهم وتحسين تركيزهم أثناء الدراسة

## إيش هو المشروع؟

مشروع تعليمي بسيط يشرح أفكار وتقنيات عملية تساعد أي طالب يدير وقته بشكل أفضل، ويقلل من التسويف، ويرفع مستوى تركيزه أثناء المذاكرة

## كيف يستخدم؟

افتحي ملف [guide.md](./guide.md) لقراءة الدليل كامل. الدليل مقسّم لأربعة أقسام:

1. تنظيم الجدول الدراسي
2. تقنية بومودورو للتركيز
3. التعامل مع التسويف
4. التوازن بين الدراسة والراحة

## عن المشروع

هذا المشروع من ضمن تدريبي على استخدام Git وGitHub — تدربت فيه على إنشاء Branch، عمل أكثر من Commit، ورفع التعديلات عبر Pull Request
